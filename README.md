# Studio Base Visual — MVP 1.2

Versão evolutiva do MVP 1.1. Preserva a logomarca e fotografia autoral, o portfólio e as coleções, acrescentando comunicação alinhada ao documento fornecido por Suzane.

## Executar
Abra `index.html` no navegador ou use Live Server no VS Code.

## Páginas
- `index.html`: apresentação, identidades visuais, canecas, sobre, processo e contato.
- `projeto.html?id=eduardo` (ou `diana`, `guitarra`): projetos.
- `colecoes.html`: galeria e duas modalidades de personalização.
- `sobre.html`: trajetória de Suzane.

## Contato
Em `app.js`, preencha `WHATSAPP_NUMBER` com DDI+DDD+número (somente dígitos). Sem o número, os botões abrem um e-mail de contingência. O WhatsApp ainda **não está ativado**.

## Pendências de validação
- Confirmar número comercial do WhatsApp.
- Validar textos comerciais, nomes e categorização das imagens das canecas.
- Confirmar autorização para divulgação dos trabalhos de clientes e eventuais depoimentos.
- Confirmar se existe um formulário estratégico público; por enquanto o CTA solicita o formulário via contato.
- Revisar a paleta oficial por amostragem exata dos arquivos de marca.
- Realizar testes completos de navegação, responsividade e acessibilidade antes da publicação.
